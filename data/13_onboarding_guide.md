# Getting Started with CloudFlow

## Welcome
This guide helps new users get up and running with CloudFlow in under 30 minutes.

## Step 1: Complete Your Profile
1. Click your avatar in the top-right corner
2. Select "Profile Settings"
3. Add your name, photo, and timezone
4. Set your notification preferences

## Step 2: Create Your First Project
1. Click the plus button in the sidebar
2. Choose a template or start blank
3. Name your project and add a description
4. Set project visibility (Private, Team, or Organization)

## Step 3: Add Team Members
1. Go to Settings then Team then Invite Members
2. Enter email addresses (bulk invite supported)
3. Assign roles (Viewer, Member, or Admin)
4. Set project-level permissions

## Step 4: Create Tasks
1. Open your project
2. Click "New Task" or press Ctrl+N
3. Fill in: Title, Description, Assignee, Due Date, Priority
4. Add labels and custom fields as needed
5. Use subtasks for complex items

## Step 5: Explore Key Features
- Boards: Kanban view for workflow visualization
- Timeline: Gantt chart for project planning
- Time Tracking: Log hours on tasks
- Automations: Create rules to automate repetitive work
- Reports: Generate progress and performance reports

## Keyboard Shortcuts
- New task: Ctrl+N
- Search: Ctrl+K
- Quick add: Ctrl+Shift+N
- Toggle sidebar: Ctrl+B
- Command palette: Ctrl+Shift+P
