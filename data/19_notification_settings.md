# Notification Settings

## Notification Channels
- In-app: Bell icon in the top navigation bar
- Email: Sent to primary email address
- Mobile push: Via CloudFlow mobile app
- Slack: Via Slack integration
- Webhook: Custom webhook endpoint

## Configuring Notifications
Go to Settings then Notifications to customize:

### By Event Type
- Task assigned to me
- Task completed
- Comment on my task
- Mentioned in comment (@username)
- Due date approaching (1 day, 3 days, 1 week)
- Project status change
- Team member joined or left

### By Channel
Toggle each event type for each channel independently.

## Digest Mode
Instead of real-time notifications:
1. Go to Settings then Notifications then Digest
2. Choose frequency: Daily or Weekly
3. Select delivery time
4. Digest includes all activity summary

## Do Not Disturb
- Set quiet hours (e.g., 10 PM to 8 AM)
- Emergency notifications bypass DND
- Per-project DND settings available
- Calendar integration: Auto-DND during meetings

## Slack Integration Setup
1. Go to Settings then Integrations then Slack
2. Click "Add to Slack"
3. Authorize the CloudFlow app
4. Select channels for notifications
5. Map projects to Slack channels

## Troubleshooting Notifications
- Not receiving emails: Check spam, verify email address
- Push notifications not working: Check device permissions
- Too many notifications: Adjust event filters
- Slack not posting: Re-authorize the integration
