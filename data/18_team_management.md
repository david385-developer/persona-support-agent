# Team Management Guide

## Inviting Team Members
1. Go to Settings then Team then Members
2. Click "Invite Members"
3. Enter email addresses (comma-separated for bulk)
4. Select role: Viewer, Member, Admin
5. Choose projects to assign
6. Send invitations

Invitation expires: 7 days
Resend: Click the pending invitation and select "Resend"

## Roles and Permissions

### Viewer
- View tasks: Yes
- Create or edit tasks: No
- Delete tasks: No
- Manage projects: No
- Invite members: No
- Manage billing: No

### Member
- View tasks: Yes
- Create or edit tasks: Yes
- Delete tasks: No
- Manage projects: No
- Invite members: No
- Manage billing: No

### Admin
- View tasks: Yes
- Create or edit tasks: Yes
- Delete tasks: Yes
- Manage projects: Yes
- Invite members: Yes
- Manage billing: No

### Owner
- All permissions: Yes
- Delete workspace: Yes

## Custom Roles (Enterprise)
Create custom roles with granular permissions:
1. Go to Settings then Team then Roles
2. Click "Create Custom Role"
3. Name the role and set permissions
4. Assign to team members

## Removing Members
1. Go to Settings then Team then Members
2. Click the member name
3. Select "Remove from Workspace"
4. Choose: Transfer owned items or delete them
5. Confirm removal

Note: Removed members lose access immediately. Their contributions (comments, tasks) are preserved.

## Teams and Groups
- Create teams for department organization
- Assign projects to teams
- Use team-based permissions
- Nested teams supported (max 3 levels)
